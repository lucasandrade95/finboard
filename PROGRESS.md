# Progresso

- **2026-08-21** — Paginação na listagem: GET `/api/transactions` agora aceita `limit` (1–100, padrão 20) e `offset` (padrão 0), validados por Zod com coerção de string, e devolve `{ items, total, limit, offset }` — o `total` respeita o filtro de mês, então a UI sabe quantas páginas existem sem buscar tudo. Na tabela, controles "Anterior/Próxima" com "Página X de Y" (só aparecem quando há mais de uma página), página volta para 1 ao trocar de mês e, se a última transação de uma página for excluída, a UI recua sozinha para a última página válida. Cinco testes novos no server (fatia correta com offset, total preservado, limites rejeitados com 400) e dois de componente (navegação chama onPageChange, controles escondidos com página única).

- **2026-08-20** — Edição de transações: novo endpoint PUT `/api/transactions/:id` (substituição completa validada por Zod, 200 com o registro atualizado, 404 se não existe, 400 para payload inválido) e edição inline na tabela — o botão "Editar" transforma a linha em formulário com todos os campos preenchidos, com Salvar/Cancelar. A mutação invalida lista e resumo no TanStack Query, então os cards recalculam sozinhos. Três testes novos no server (incluindo reflexo no resumo e que payload inválido não altera nada) e dois testes de componente na lista (abrir com valores preenchidos e cancelar sem salvar).
- **2026-08-20** — Exclusão de transações: novo endpoint DELETE `/api/transactions/:id` (204 no sucesso, 404 se não existe, 400 para id inválido via Zod) e botão "Excluir" em cada linha da tabela, com confirmação antes de apagar. A mutação do TanStack Query invalida lista e resumo, então os cards atualizam sozinhos após excluir. Três testes novos no server cobrem os três status.
- **2026-08-20** — Bootstrap do projeto: monorepo npm workspaces com API Fastify/TypeScript (transações + resumo mensal, SQLite, Zod, testes com inject) e SPA React/Vite (dashboard com cards de resumo, formulário e listagem, TanStack Query). CI no GitHub Actions rodando lint, format, testes e build.
